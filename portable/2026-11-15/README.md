# 换电脑恢复 · 盘整 1.25 + Book 1.248 + 旗楔 1.249

此目录提供 2026-11-15 当前运行组合的恢复快照，补齐旧备份中的盘整版本差异、后台更新、历史索引、离线 Python 依赖和安装工具。所有分卷均在本仓库内，不依赖旧电脑或网盘。

## 使用方法

新电脑先准备 **Windows x64、Python 3.12 x64、MT5**，自行登录对应的 TMGM 行情账户。这些系统环境和账户登录不由仓库替代。

**方法一：下载整个仓库 ZIP 或 git clone 后，在仓库目录运行：**

```powershell
py -3.12 portable\2026-11-15\download.py --offline
```

**方法二：只下载本目录的 `download.py`，在其所在目录运行：**

```powershell
py -3.12 download.py
```

脚本会从 GitHub 固定到同一提交读取分卷，校验、合并并解压到新建的 `OT-Recovery-Package`；已存在目录不会覆盖。可用 `--destination "D:\OT-Recovery-Package"` 指定位置。它只下载与解压，不会自动运行后台或更改 MT5。

随后阅读解压目录的 `README.md`，在包目录运行：

```powershell
py -3.12 restore.py --verify-only
py -3.12 restore.py --check-only --terminal-data "MT5文件菜单中打开的数据文件夹路径"
py -3.12 restore.py --terminal-data "MT5文件菜单中打开的数据文件夹路径"
```

安装器将使用随包 wheels 离线建立 Python 环境，恢复历史索引、三个指标和干净模板，自动写入新电脑桥接路径。安装后运行新后台目录的 `START.cmd`，在新建 XAUUSD H1 图表应用 `OT_Consolidation_1.25_Book_1.249` 模板，按包内说明设置按钮，再运行 `VERIFY.cmd` 检查实际状态。
